<p align="center">Uma aplicação que auxilia na criação de currículo profissionais.</p>

<h2 align="center">Sobre</h2>
<p align="center">
  CurrículoGen é uma aplicação web que facilita no desenvolvimento de currículos         modernos e profissionais. A plataforma conta com modelos de currículos prontos,        seletor de cores, formulário interativo, preview do processo de criação do currículo   e download em formato pdf.
</p>
